下载与安装 DevControl Next Agent

Windows、Android、Linux 各有独立安装包。支持下载后安装，也支持一条命令安装。DevControl Next 与原单用户 DevControl 的 Agent、密钥和设备数据完全隔离。

当前开放的是 QA 预览下载，不是已上线的远程控制服务。 Windows 使用未正式签名的测试二进制；Android 使用调试签名。Next 的 mcpx/Authx 尚未上线，安装后暂不能完成配对或连接 ChatGPT。请勿安装在重要生产设备上。

x64 · QA Preview

一条命令安装

Windows（PowerShell）

irm https://raw.githubusercontent.com/star8592/DevControl-Next-Downloads/main/install.ps1 | iex

Linux（终端）

curl -fsSL https://raw.githubusercontent.com/star8592/DevControl-Next-Downloads/main/install.sh | bash

Android（已连接 USB 调试、安装 ADB 的电脑）

curl -fsSL https://raw.githubusercontent.com/star8592/DevControl-Next-Downloads/main/install-android.sh | bash

如果 Windows 网络无法解析 raw.githubusercontent.com，可以在 CMD 命令提示符 使用下面这一条 Git 备用命令（需要安装 Git for Windows，已通过 Windows 真机安装/卸载测试）：

git clone --depth 1 -b upload/windows-preview-r1 https://github.com/star8592/DevControl-Next-Downloads.git "%TEMP%\dcn-next" && powershell -NoProfile -ExecutionPolicy Bypass -File "%TEMP%\dcn-next\install-local.ps1"

该命令克隆只包含公开预览二进制的独立分支，先核验 SHA-256 再安装，绝不覆盖单用户 Agent。

首次连接流程

  1. 选择平台并执行安装命令（当前为 QA 预览包）。
  2. 待独立 Next Gateway 上线后，登录自己的 Next 账户与工作空间。
  3. 在设备端与浏览器核对一次性配对码，确认设备归属。
  4. 在 ChatGPT 中连接 https://mcpx.devcontrol.dev/mcp。
  5. 执行真实 echo 任务，获取执行回执。当前第 2—5 步尚不可使用。
